過去日の推定総消費を確定保存して表示

理由:
過去日の推定総消費を基礎代謝量や歩数の変更で変動させず、確定値として保持するため

変更点:
- SQLiteデータベースをバージョン6へ更新し、日別推定総消費スナップショットを追加
- 過去日の未確定歩数を起動時、同期後、再読み込み前、手入力後、基礎代謝量保存前に確定
- 保存済みスナップショットを設定画面とメイン画面の選択日へ表示
- 当日だけを現在の歩数と基礎代謝量から動的計算し、未来日と未確定過去日はハイフン表示
- 基礎代謝量保存をIO上のcommitへ変更し、確定処理失敗時の保存を抑止
- 計算、スナップショット保存、再計算防止、表示解決の試験を追加

確認内容:
- 単体試験を実行し成功
- デバッグ用アプリの組み立てを実行し成功
- デバッグ静的解析を実行し成功
- 接続端末 CPH2199 で接続端末試験2件を実行し成功
- 実機で過去日の選択時に推定総消費が表示されることを確認
- 差分の空白検査を実行し成功
