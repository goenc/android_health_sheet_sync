全手入力経路のスプレッドシート同期を即時化

理由:
手入力画面と共有取込で追加・変更した健康データを、保存直後にスプレッドシートへ反映するため

変更点:
- 手入力6種類の保存後に自動同期を即時開始
- 共有テキスト取込後の自動同期を即時開始
- 手入力記録と保存済み記録の無効化・復元・削除後も即時同期
- 同期中に追加された入力を保留し、同期完了後に再実行
- 手動同期時も端末データベースの最新状態を読み込み

確認内容:
- `:app:testDebugUnitTest` 成功
- `:app:assembleDebug` 成功
- `adb install -r` による既存データ保持更新成功
- 更新後も対象パッケージが端末に存在することを確認
