# 今の食事内容

メイン画面下部の「検査結果」と横並びの「今の食事内容」から開く。画面を開いた時と「更新」を押した時にGoogle認証し、PfcPlanBoardの同期履歴からプラン一覧の先頭を表示する。

## 認証と参照元

- 読込スコープ: `https://www.googleapis.com/auth/drive.appdata`
- 保存先: Google Driveの非表示アプリ専用領域 `appDataFolder`
- データセット: `9b0db1ba-7ee0-4cf3-9b9b-84f674a8d1bb`
- 対象ファイル: `pfc-sync-` を名前に含む、削除されていない同期ファイル

同じGoogleアカウントでも、HealthSheetSyncのOAuth設定でPfcPlanBoardのアプリ専用領域を読めるとは限らない。初回の実機確認では、認証完了後に対象ファイルが一覧取得できることを先に確認する。ファイルが見つからない場合は画面に案内を表示する。通常DriveフォルダのZIPやGoogle Sheetsへ自動的に切り替えない。

## 表示と更新

ページングして全履歴を取得し、エンティティと行キーごとに最新revisionを採用する。削除履歴も保持して、古い更新による復活を防ぐ。プラン内容は保存時のスナップショットから復元し、現在の食品・料理マスターでは置き換えない。

一覧の先頭はPfcPlanBoardと同じく `displayOrder`、`createdUtcTicks` の昇順で決める。選択中・お気に入り・更新日時の新しさでは決めない。アーカイブ済みのプラン・食事・明細は表示しない。

表示対象はプラン名、食事とその内容、分量、メモ。栄養計算や画像の取得は今回の対象外。取得結果は画面の状態に保持し、更新失敗時は前回取得した内容であることを明記する。Driveの同期データは変更しない。
