# メイングラフの表示範囲

メインの左端の期間ボタンは、選択中に押すと「2か月 → 3か月 → 4か月 → 5か月 → 6か月 → ALL → 2か月」の順に切り替わる。ALLは保存済み体重データの全期間。右の1か月・2週間・1週間は固定。右の期間から左へ戻す場合は前回選んだ長期の期間を表示し、初回は2か月になる。

メインの歯車から設定を開き、「グラフの表示範囲」を押す。
体重（kg）、歩数（歩）、血糖値（mg/dL）、HbA1c（%）、腹囲（cm）、血圧（mmHg）の最小値・最大値を項目ごとに入力して「保存」。血圧は上・下の共通軸。

最小値は0以上、最大値は最小値より大きい有限の数値。小数にも対応する。空欄、不正な数値、逆転した範囲は保存しない。「自動」でその項目だけ従来の表示範囲へ戻す。
未設定の項目は従来の自動計算または既定範囲を使用する。設定は端末内に保存し、再起動後も維持する。保存後メインへ戻ると反映される。検査結果のグラフには適用しない。

手動設定した範囲外の値は描画領域の端へ収める。保存範囲は表示の調整だけで、元の健康データや基準値の判定を変更しない。
